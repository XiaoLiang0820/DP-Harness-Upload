## 功能

- 垃圾清理（临时文件 / 缓存 / 系统残留，14 类）
- 游戏加速（电源计划 / 内存释放 / 后台进程 / 游戏模式）
- 游戏专属优化（四款内置 + 检测/添加其他游戏）
- 激进网络优化（CS2 / PUBG 延迟）
- 启动项管理 / 磁盘空间分析 / 硬件信息
- 开机自启清理 / 定时清理
- 首页实时看板（内存 / CPU / 显存扇形图 + 电源计划/游戏模式/GPU 加速开关）

## 使用

解压后双击 FrameBoost.exe。系统级功能（电源计划 / 网络优化 / GPU 加速）需右键以管理员身份运行。
