## 首次运行提示（SmartScreen）

本程序未做代码签名，Windows 可能弹出「Windows 已保护你的电脑」。
- 点「更多信息」→「仍要运行」即可
- 或 PowerShell 执行 Unblock-File FrameBoost.exe
- 彻底解决需购买代码签名证书

## 使用

解压后双击 FrameBoost.exe。系统级功能需右键以管理员身份运行。
