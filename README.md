## 更新日志

### v1.3.0（设备自适应）
- 自动识别设备类型：台式机 / 游戏本 / 轻薄本（按有无电池 + 是否独显）
- 自动识别 OEM（华硕/联想/戴尔/惠普/MSI/宏碁/雷蛇等）
- 智能加速：按设备推荐「激进 / 均衡 / 温和」档位，一键应用
- 电池感知：电池供电时自动温和优化
- 显卡厂商识别（NVIDIA / AMD / Intel 核显）
- 核显共享显存读取（解决核显显存显示 0%）
- AMD 显卡显存读取（WMI 性能计数器）
- 独显直连（MUX）/ OEM 性能模式 / 高刷新率 提示
- 性能悬浮窗（置顶、可拖动，显示 CPU / 内存 / 进程）
- 一键导出诊断报告

## 功能

- 垃圾清理（14 类）
- 游戏加速（电源 / 内存 / 进程 / 游戏模式 / 定时器 / 电源细化 / Game DVR）
- 设备自适应智能加速（台式 / 游戏本 / 轻薄本）
- 游戏专属优化（四款内置 + 检测/添加 + 全屏优化）

解压后双击 FrameBoost.exe。系统级功能需右键以管理员身份运行。
